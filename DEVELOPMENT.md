## Решения для реализации

- Размещать двери по центрам доступных стен. Для узоров использовать локальные координаты поверхности со стабильным началом, чередование по сумме координат для шахмат, полосы шириной один блок и крапинки в сетке 3×3. Двери, окна и проходы пропускают соответствующие позиции узора. Список заказа показывает оба материала для самостоятельной добычи.
- Для стен, пола и потолка выбрать проверяемый каталог подходящих состояний блоков с отдельной проверкой роли и опоры. Доступность и тир брать из §11. Контейнеры, двери, окна, свет и мебель проверяются по собственным ролям. У двух материалов одной поверхности при узоре должны различаться идентификаторы.
- Для штрафа каждая позиция учитывается один раз. Пропущенная или неверная позиция нарушает одну группу по её назначению в чертеже. Например, четыре ошибки стены и две ошибки окна означают шесть позиций и два критерия. Проверки геометрии и прохода учитываются по их собственным условиям.
- При совпадении действий в одном тике сначала обработать достигнутый срок. Любое действие из меню проверяет актуальное состояние заказа и может изменить его только один раз.
