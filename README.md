# Мегастройка

Мод для Minecraft: Java Edition 1.20.1 на Forge. Строитель предлагает игроку работу в строительной конторе. Игрок получает землянку, ходит в офис к прорабу, берёт заказы и строит комнаты по полупрозрачным чертежам в отдельном измерении — недостроенной восьмиэтажке. За сданные комнаты прораб платит изумрудами, за недострой штрафует, а штрафы можно оспорить.

Версия 0.1.0 — первая устанавливаемая. Она рассчитана на одиночную игру.

## Что нужно

| Компонент | Версия |
| --- | --- |
| Minecraft: Java Edition | 1.20.1 |
| Forge | 47.4.28 или новее в линейке 1.20.1 (47.x) |
| Java | 17, идёт вместе с официальным лаунчером |
| Другие моды | не требуются |

## Установка

1. Запустите Minecraft 1.20.1 один раз через официальный лаунчер, чтобы игра скачалась.
2. Скачайте установщик Forge 1.20.1-47.4.28 со [страницы Forge](https://files.minecraftforge.net/net/minecraftforge/forge/index_1.20.1.html), запустите его и выберите **Install client**.
3. Положите файл `buildersmod-0.1.0.jar` в папку `mods` игрового каталога. В Windows это `%APPDATA%\.minecraft\mods`. Если папки нет, создайте её.
4. В лаунчере выберите профиль **forge** и нажмите «Играть». Мод «Мегастройка» должен появиться в списке на экране **Mods**.

## Как попробовать основную механику

1. Создайте новый мир в режиме выживания. Сложность — любая, кроме мирной: на мирной недоступны заказы на выселение.
2. Рядом с точкой появления стоит **Строитель**. Нажмите по нему правой кнопкой и выберите в чате **[Принять работу]**. Рядом появятся землянка и офис конторы.
3. Дождитесь следующего игрового дня, можно поспать в землянке. В офисе нажмите правой кнопкой по **Прорабу** и выберите «Открыть заказы». Первая карточка — пробная комната 5×5.
4. Нажмите «Принять заказ» и войдите в голубой портал в офисе. Вы окажетесь в стартовой комнате на стройке. За её дверью висит чертёж: синие силуэты показывают, каких блоков не хватает, красная рамка — блок не того типа. Клавиша **B** скрывает и показывает чертёж. Название заказа и остаток срока видны вверху слева.
5. Постройте комнату по чертежу. Список материалов и прогресс показывает карточка заказа у прораба. Три торта внутри комнаты дают бонус.
6. Вернитесь в офис через портал в углу стартовой комнаты, откройте заказы и нажмите «Сдать», затем «Забрать зарплату».

Инструменты продаёт строитель в офисе, материалы из дальних биомов — странствующий торговец. Оба принимают изумруды.

## Что ещё есть в версии 0.1.0

- Случайные заказы пяти уровней сложности: размер, этажность, узоры, окна, свет и мебель комнаты выбираются по весам из [REQUIREMENTS.md](REQUIREMENTS.md).
- Сроки, покупка дополнительных суток, премия за досрочную сдачу.
- Штраф и задание на снос за проваленный или отменённый заказ. Штраф можно оспорить в мини-игре с карточками.
- Отдельные заказы: лестница с открытием следующего этажа, дворик за окном, запасной коридор.
- Происшествия в построенных комнатах: очистка от паутины и граффити, выселение, пожар, потоп. Раз в семь игровых дней происшествие может случиться само, тогда прораб звонит игроку.

## Ограничения

- Только одиночная игра. Выделенный сервер не поддерживается.
- Тексты интерфейса — на русском языке.
- Окна в заказах выходят только на свободное пространство стройки.
- Прокачка игрока и рабочие-миньоны запланированы после первой версии.

## Сборка из исходников

Нужен JDK 17. Команда из корня репозитория:

```
gradlew build
```

Готовый файл — `build/libs/buildersmod-0.1.0.jar`. Одни и те же исходники дают побайтно одинаковый JAR.

## Проверки

| Команда | Что делает |
| --- | --- |
| `gradlew build` | Собирает JAR и запускает тесты JUnit. |
| `gradlew runGameTestServer` | Запускает Forge GameTest на сервере с пустым тестовым миром. |
| `gradlew runClient -Pwalkthrough=main` | Сам проходит в клиенте путь от встречи со строителем до первой зарплаты. Вместо `main` можно указать `fines`, `incidents` или `hazards`. Отчёт и снимки пишутся в `run-walkthrough`. |
| `gradlew walkthroughJar` и `python scripts/packaged_client.py …` | Тот же сценарий в установленном клиенте Forge, без среды разработки. |

Требования и критерии приёмки описаны в [REQUIREMENTS.md](REQUIREMENTS.md), ход работ и результаты проверок — в [DEVELOPMENT.md](DEVELOPMENT.md), загрузки и установки — в [INSTALL_LOG.md](INSTALL_LOG.md) и [INSTALL_LOG_NIKOLAY.md](INSTALL_LOG_NIKOLAY.md).
